# MEARCO Assist ONE V2 — website + mobile, one backend

Replacement code based on the previously generated unified pilot, redesigned to resemble the screenshot: dark teal MEARCO Assist 24/7 header, Operations Overview, six metric cards, policies, tow balances, dispatch portal, users/roles info, client page, chat demo and garage/provider registry. The iOS/Android **source project** connects to the same API as the website.

Working pilot: role-scoped policy API, Excel policy import, motor assistance cases, towing entitlement, MEARCO-only dispatch update, garages/providers, unpaid balances, pending payment requests, basic FAQ bot. Admin roles are seeded locally using `backend/seed_demo.py`.

NOT included: actual previous v0.7 source, customer mobile store binaries, live AI answering phone, live WhatsApp, live card/Whish checkout, broker commission engine, app push notifications, fully operational real-world garage claim approvals or production compliance certification.

Run details in START_HERE.md. All Excel records are fictional. Pilot must not contain confidential client data until authentication, authorization, infrastructure, and regulatory requirements have been independently reviewed.
