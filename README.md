# MEARCO Assist v0.4 – Safe website chatbot demo

Replace your existing GitHub application files with this package, preserving `templates/` and `static/` folders. Render can redeploy from the same repository. Keep ADMIN_PASSWORD and SESSION_SECRET configured.

- `/chat` – interactive WhatsApp-style **website** demo, no WhatsApp number needed. Fictional categories, safety choices, areas and scenarios.
- `/assist` – public landing page links to chat demo. Real public intake still disabled by default.
- `/` – protected dashboard displays the dummy case generated by the chatbot.
- `/version` – version 0.4.0.

TEST ONLY. No production-grade database, hotline, WhatsApp, monitored dispatch or alerts. The demo inserts fictional records into SQLite; they may disappear on Render restarts. Do not enter real personal details or send this URL as a working emergency service.

For future production: durable PostgreSQL database, multiuser authentication, staff notifications, 24/7 staffing, abuse controls and secure policy handling.
